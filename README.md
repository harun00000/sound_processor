# Sound Processor

Консольное приложение на C++20 для обработки WAV-файлов с помощью последовательного применения аудиофильтров.

## Возможности

Программа поддерживает следующие операции:

- **Amplification** — изменение громкости звука.
- **Normalization** — нормализация амплитуды.
- **Silence** — добавление тишины.
- **Time stretching** — изменение длительности аудио.
- **Low-pass filtering** — низкочастотная фильтрация.
- **Reverse** — воспроизведение аудио в обратном порядке.
- **Cut** — обрезка аудио.
- **Absolute** — взятие абсолютного значения аудиосэмплов.
- **Signal generation** — генерация синусоидальных, AM- и FM-сигналов.

Фильтры можно комбинировать и применять последовательно.

## Структура проекта

- `app/` — точка входа в приложение.
- `include/` — заголовочные файлы и интерфейсы.
- `src/` — реализация обработки аудио, работы с WAV-файлами, фильтров и конвейера обработки.
- `tests/` — модульные тесты.
- `CMakeLists.txt` — конфигурация сборки проекта.
- `Doxyfile` — конфигурация генерации документации.

## Сборка

Для сборки необходимы компилятор с поддержкой C++20 и CMake версии 3.22 или выше.

```bash
cmake -S . -B build
cmake --build build
```

После сборки исполняемый файл находится по пути `build/bin/sound_processor`.

## Использование

Пример запуска с одним фильтром:

```bash
./build/bin/sound_processor -i input.wav -o output.wav -f reverse
```

Основные аргументы командной строки:

- `-i` — путь к входному WAV-файлу.
- `-o` — путь к выходному WAV-файлу.
- `-f` — название фильтра и его параметры.

Для последовательного применения нескольких фильтров нужно указать несколько аргументов `-f`:

```bash
./build/bin/sound_processor \
    -i input.wav \
    -o output.wav \
    -f ampl 0.5 \
    -f normalize 1.0 \
    -f reverse
```

Если выходной файл уже существует, программа запрашивает подтверждение перезаписи.

## Тестирование

Проект содержит модульные тесты с использованием фреймворка Catch2.

Сборка и запуск тестов:

```bash
cmake -S . -B build -DBUILD_TESTS=ON
cmake --build build
./build/bin/tests
```
